# Adeola & Joshua: Traditional Wedding

Wedding website for the traditional wedding of Adeola Olorunfemi and Joshua Nwabogor,
Thursday 26 November 2026, 11:00 am, Blossom Hall, Watercress Hotel, Ikeja, Lagos.

It is a static site: open `index.html`, or serve the folder from any web host.

## What is here

- `index.html`: the whole site (intro, invitation, order of the day, details, story, photos)
- `img/`: proposal photographs by Suafuong
- `audio/`: intro sounds (djembe phrase and harp run)
- `og.jpg`: the picture chat apps show when the link is shared

## Publish with GitHub Pages

1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
3. The site appears at `https://joshbog.github.io/wedding_invite/` within a minute or two.

To use your own domain, enter it under **Custom domain** on the same page and follow the DNS instructions GitHub shows.
When the final address is known, change `og:image` in `index.html` to the full address of `og.jpg` so link previews show the picture.
